# Верстак — заметки для Claude Code

3D-гайд ферм Minecraft Java 26.3 и шпаргалки (жители, зелья, советы). Чистый HTML + ES-модули, сборки нет.
Выкладывается на GitHub Pages как PWA: https://gusenichka709.github.io/verstak/
Это единственная живая версия; старую страницу на claude.ai не обновляем.

## Устройство
- `index.html` — разметка и стили; `app.js` — вкладки, выбор фермы, шаги, материалы, шпаргалки.
- `engine.js` — 3D-просмотрщик (three.js из `vendor/three/`, import map в index.html). Рисует только по изменениям: после любой правки сцены ставь `this.dirty = true`.
- `blocks.js` — блоки и фишки мобов; все текстуры рисуются кодом на canvas. Игровые текстуры и модели мобов не копировать.
- `farms/<id>.js` — одна ферма = один файл данных; порядок в `farms/index.js`. Шаблон и правила — в навыке mc-farm-3d.
- `cheats/*.js` — данные шпаргалок.
- `sw.js` — офлайн-кэш. **При любом изменении файлов подними `VERSION`, новые файлы добавь в `FILES`.**

## Проверка
`python3 -m http.server 8765` и открыть `http://localhost:8765/#iron` (там же работает офлайн-воркер).
Пройтись по всем фермам через список слева, по шагам, по вкладкам; в консоли не должно быть ошибок.

## Правила
- Название «Верстак»; слово Minecraft только во второстепенном тексте, дисклеймер в подвале не убирать.
- Данные о механиках и сделках сверять с источниками по текущей версии Java, не по памяти.
- Тексты на сайте — по-русски, на «ты», коротко.
